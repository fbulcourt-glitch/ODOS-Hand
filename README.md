# ODOS-Hand — Interface Web BLE

Application web progressive (PWA) conçue pour la communication et le paramétrage sans fil d'un outil de mesure numérique via Bluetooth Low Energy (BLE).

## Fonctionnalités

- **Liaison sans fil directe :** Connexion rapide via l'API Web Bluetooth, sans passerelle intermédiaire.
- **Télémétrie :** Lecture du niveau de batterie du dispositif.
- **Paramétrage :** Définition et envoi d'une consigne de distance cible.
- **Historique :** Synchronisation et affichage des dernières mesures enregistrées.
- **Installation locale :** Fonctionne comme une application autonome (PWA) sur smartphone.

## Compatibilité

- **Android :** Google Chrome (support natif et installation PWA).
- **iOS / iPadOS :** Navigateurs compatibles Web Bluetooth (ex. *Bluefy*).
- **Desktop :** Google Chrome, Microsoft Edge (avec Bluetooth activé).

## Utilisation

1. Activer le Bluetooth sur le smartphone.
2. Basculer l'outil en mode appairage.
3. Ouvrir l'application, appuyer sur **Connect** et sélectionner le périphérique dans la liste.
4. Ajuster la consigne ou synchroniser les données selon les besoins.
